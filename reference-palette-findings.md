# Lundani Studio Reference Palette Findings

Source reviewed: `view-source:https://lundanistudio.framer.website/`
Live page reviewed: `https://lundanistudio.framer.website/`

The reference presents a predominantly white canvas with near-black editorial text and very restrained borders. The rendered homepage uses a clean white background, black/near-black typography, and muted photographic imagery; no purple or beige UI tint is part of the visible UI system. The recolor target for the birthday site is therefore a strict monochrome base plus the existing cherry-red accent, while preserving the birthday site’s layout and imagery.
